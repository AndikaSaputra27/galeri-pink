# 🌸 Galeri Foto Elegan — Pink Edition

> Galeri foto interaktif bertema pink elegan dengan animasi confetti, lightbox, dan fitur share publik.

## ✨ Fitur Utama

- 🎊 **Animasi Confetti** — lingkaran, kotak, segitiga & hati berwarna pink terus bergerak
- 🌸 **Emoji Mengambang** — bunga & hati bergerak lembut di background
- 📸 **6 Slot Foto** — upload gambar langsung dari perangkatmu
- 💾 **Auto-Save** — foto tersimpan otomatis via `localStorage`, tidak hilang saat refresh
- 🔍 **Lightbox** — klik foto untuk lihat ukuran penuh
- 🔗 **Fitur Share** — salin link, bagikan via WhatsApp, Instagram, atau unduh halaman
- 📱 **Responsive** — tampil sempurna di HP, tablet, maupun desktop

## 🛠️ Cara Pakai

### Online (GitHub Pages)
Langsung buka link demo di atas — tidak perlu install apapun!

### Offline / Lokal
```bash
git clone https://github.com/AndikaSaputra27/galeri-pink.git
cd galeri-pink
# Buka galeri-pink.html di browser
start galeri-pink.html
```

### Upload Foto
1. Buka halaman galeri
2. Klik salah satu dari **6 kartu foto** (berlabel Foto 1 – Foto 6)
3. Pilih gambar dari perangkatmu
4. Foto langsung tampil dan tersimpan otomatis
